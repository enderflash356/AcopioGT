# Sistema de Gestión de Inventario - AcopioGT

Proyecto desarrollado en Java para el **Laboratorio 4 (Polimorfismo)** del curso *CC2008 - Programación Orientada a Objetos* de la Universidad del Valle de Guatemala (UVG).

## Descripción
Sistema de consola que gestiona la recepción, almacenamiento, control de vencimientos y despacho de productos agrícolas (Café en pergamino, Café orgánico, Cardamomo, Hortaliza y Queso fresco) aplicando herencia, clases abstractas, interfaces y polimorfismo.

## Requisitos
- Java Development Kit (JDK) 17 o superior instalado.

## Instrucciones de Compilación y Ejecución
1. Abrir una terminal dentro de la carpeta raíz del proyecto (`AcopioGT`).
2. Compilar todos los archivos fuente:
   ```bash
   javac *.java
